# Hospital Management System

## Project Description
The Hospital Management System is a simple frontend CRUD (Create, Read, Update, Delete) web application developed using HTML, CSS, and JavaScript.

https://venkatanavaneetha.github.io/Hospital-Management-System/

This application helps manage patient information, including adding new patients, viewing patient details, updating records, and deleting patient records.

## Technologies Used
- HTML5 – Structure of the application
- CSS3 – Styling and layout
- JavaScript – Application functionality
- Local Storage – Storing patient records in the browser
- Git – Version control
- GitHub – Project hosting and code management

## Features
- Add new patient details
- View all patient records
- Edit existing patient information
- Delete patient records
- Search patient details
- Dashboard with patient information count
- Store data using browser Local Storage

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/venkatanavaneetha/Hospital-Management-System.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html`.

4. Right-click and select **Open with Live Server**.

5. The application will open in your web browser.

## CRUD Operations

| Operation | Description |
|---|---|
| Create | Add new patient records |
| Read | View patient records |
| Update | Edit patient details |
| Delete | Remove patient records |
